* Plottr Components
 - Technical: optimise ~PlottrFloater~ to only re-render when props
   other than it's component change.
 - Technical: optimise ~CharacterListView~ to re-render less by not
   passing it all characters.
 - Technical: only release the RCE lock if we have a user id.
 - Technical: optimise the ~CardDialog~: memoise the ~closeColourPicker~
   function.
 - Technical: optimise the ~TimelineTable~: stop re-rendering when the
   ~CardDialog~ is open.  Receives whether the card dialog is open from
   the ~TimelineWrapper~.

* Plottr Firestore
 - Technical: new ~firestore.rules~ rules:
   - Technical: add ~delete~ to ~cards~, ~characters~, ~notes~, & ~places~.
   - Technical: add permissions to ~old*~ and ~flat*~ for migrations and
     for infinite collections, where ~*~ can be ~cards~, ~characters~, ~notes~
     or ~places~.
 - Technical: add delete and on snapshot for the mobile version of
   ~plottr_firebase~.
 - Technical: add initial fetch capabilities for ~flat*~ collections:
   - Technical: non-flat collections are migrated to flat collections,
     and
   - Technical: backed-up into old collections.
 - Technical: add listen capabilities to listen to the flat collections.
 - Technical: re-interpret requests to patch flat collections when
   requests would instead modify old non-flat collections.
 - Technical: handle snapshots of flat collections by checking for
   differences to the previous version correctly and only dispatch
   actions when changed.
 - Debugging: annotate all listen errors with the source of the error.
 - Technical: add handler for listening to arrays and flat arrays.
 - Technical (Migration!): add ~fetchOldArrayObject~ to fetch an old
   array object, back it up to the backups collection and write the
   values into the new flat collections.
 - Technical: modify old fetch functions to use ~fetchOldArrayObject~.
 - Technical: add new fetch functions to fetch flat array values.
 - Technical: re-interpret destination path in ~overwriteAllKeys~.
 - Technical (migration): change all timestamps on files to
   milliseconds since epoch for compatibility with Mobile.
 - Technical: add function to delete each element of a flat
   collection.
 - Technical: add functions to delete all elements of each specific
   flat array collection.
 - Technical: add function to patch without re-interpretation to
   change old collections when we need to.
 - Technical: re-interpret destination path for flat array collections
   in ~overwrite~.
 - Technical: add function to overwrite without re-interpretation to
   overwrite old collections when we need to.
 - Technical: expose new listener functions in worker, desktop index
   file and mobile.
 - Debugging: Log errors directly to console from Firebase worker so
   something is logged when connection to main JS image is broken.
